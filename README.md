# Huddle Community Page

This is a demo webpage built using **Bootstrap 5** to showcase how to create a simple and responsive community-building platform. The webpage includes various sections that demonstrate how to use Bootstrap components like navigation bars, sections with text and images, and a footer with contact information and social media links.

## Features

- **Navbar**: A responsive navigation bar with branding and a "Try it Free" button.
- **Hero Section**: A section featuring a large heading, descriptive text, and an image.
- **Content Sections**: Multiple sections that include a combination of images and text to showcase features such as "Grow Together," "Flowing Conversations," and "Your Users."
- **Footer**: A footer that contains company information, contact details, and social media links.

## Technologies Used

- **HTML5**: Structure and markup.
- **CSS**: Styling and responsiveness.
- **Bootstrap 5**: Framework used to ensure the webpage is responsive and has consistent styling.
- **Icons**: Bootstrap Icons for social media links.
